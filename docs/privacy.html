JSON Studio – Privacy Policy

Effective 16 November 2026

JSON Studio is a Chrome extension for viewing, formatting, querying and comparing JSON and similar data. It does not collect, transmit, sell or share personal data. It has no servers, accounts, analytics or advertising, and it makes no network requests.

What the extension reads

  • When you click the toolbar icon, it reads the active tab once: if the page is a JSON document it reads that text, otherwise it reads your current text selection, if any. Nothing is read in the background or from tabs you did not click on.
  • Local files you open or drop, or that you navigate to as file:// URLs ending in .json, .jsonc, .json5, .ndjson, .jsonl or .geojson.

What is stored, on your device only

  • The text that is open in each JSON Studio tab, in that tab's session storage, so a reload keeps your work. It is discarded when the tab closes.
  • When the toolbar click passes page text to the new tab, it is held briefly in the browser's in-memory extension session storage and removed as soon as the new tab has read it. It is cleared when the browser exits at the latest.
  • Interface preferences such as theme, output format and compare options, in local storage.
  • A short list of recently opened or saved files (the browser's file handles, not their contents), in this browser's IndexedDB so you can reopen them. You can clear it from the Recent menu.
  • The link between each open document and the file it came from (the browser's file handle, not the contents), in this browser's IndexedDB, so Save still writes to that file after a reload. Links unused for 30 days are removed.
  • Only if you switch on "Keep my documents between visits" (extension only, off by default): the text of your open documents, in local storage, until you switch it off, which erases it.
  • The web version at github.io runs entirely in your browser tab with no network requests. Because every project hosted under a github.io account shares one browser storage area, the web version never stores document text in local storage.

Nothing is uploaded. Remove stored data by closing the tab, clearing the extension's site data, or removing the extension.

Permissions

  • activeTab and scripting: to read the page text or selection of the tab you clicked the icon on.
  • storage: to pass that text to the new tab and to save preferences.
  • webNavigation and access to file URLs: to open a local JSON file in the studio when you navigate to it. Chrome only grants file access if you enable it for the extension.

Third parties

No data is shared with third parties. All code is bundled in the extension and no remote code is loaded. Parsing never executes the data you load.
